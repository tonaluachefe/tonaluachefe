# Tona Lua Chef - Site Oficial

Site oficial do Tona Lua Chef, apresentando receitas, dicas culinárias e muito mais.

## 🚀 Características

- Design moderno e responsivo
- Modo escuro/claro
- Navegação suave entre seções
- Filtros de receitas por categoria
- Contador animado de estatísticas
- Formulário de contato
- Galeria de imagens
- Seção de depoimentos
- Animações e transições suaves
- Totalmente responsivo para mobile, tablet e desktop

## 📁 Estrutura do Projeto

```
Site tonaluachefe/
├── index.html          # Página principal
├── manifest.json       # PWA manifest
├── README.md           # Este arquivo
├── css/
│   └── style.css      # Estilos do site
├── js/
│   └── main.js        # JavaScript para interatividade
└── images/            # Pasta para imagens
```

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (com variáveis CSS e Grid/Flexbox)
- JavaScript (Vanilla)
- Google Fonts (Playfair Display e Poppins)

## 📝 Como Usar

1. Clone ou baixe este repositório
2. Abra o arquivo `index.html` no seu navegador
3. Personalize o conteúdo conforme necessário

## 🎨 Personalização

### Cores
As cores podem ser alteradas nas variáveis CSS no arquivo `css/style.css`:

```css
:root {
    --primary-color: #d4a574;
    --secondary-color: #8b6f47;
    --dark-color: #2c2c2c;
    /* ... */
}
```

### Conteúdo
- Edite o HTML em `index.html` para alterar textos e estrutura
- Adicione suas próprias imagens na pasta `images/`
- Atualize os links das redes sociais na seção de contato

## 📱 Responsividade

O site é totalmente responsivo e funciona perfeitamente em:
- 📱 Smartphones
- 📱 Tablets
- 💻 Desktops

## 🌐 Deploy

Para fazer deploy do site:

1. **GitHub Pages:**
   - Faça push do código para o repositório
   - Vá em Settings > Pages
   - Selecione a branch main
   - O site estará disponível em `https://tonaluachefe.github.io/tonaluachefe/`

2. **Netlify/Vercel:**
   - Conecte seu repositório GitHub
   - Deploy automático a cada push
